# DSO 月结订单系统

一个零依赖的前端原型，用于承接 DSO 大客户的采购订单与月结对账流程。

## 适用场景

- 面向 DSO / 连锁口腔 / 大客户采购
- 不接在线支付，走线下回款
- 按月结算，支持账期管理
- 需要维护客户 PO、履约状态、开票与对账备注

## 当前能力

- DSO 客户档案管理
- PO 订单创建与订单明细录入
- 订单列表筛选与状态更新
- 月结汇总与对账单预览
- 发票号、回款截止日、对账备注维护
- 浏览器本地存储，刷新后数据不丢

## 使用方式

直接在浏览器打开 `index.html` 即可运行。

如果你想用本地静态服务打开，也可以执行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 文件说明

- `index.html`: 页面结构
- `styles.css`: 界面样式
- `app.js`: 数据模型、交互逻辑、本地存储
